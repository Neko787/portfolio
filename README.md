# Portfolio

My personal portfolio website — built with plain HTML and CSS.

**Live site:** https://cloud7-code.github.io/portfolio/

## What's inside

- `index.html` — the page structure: hero, about, projects, and contact sections
- `style.css` — all styling, using a dark theme with CSS custom properties

## Running it locally

No build tools needed. Clone the repo and open `index.html` in a browser:

```
git clone https://github.com/Cloud7-code/portfolio.git
```

## Status

Work in progress — the layout is done, and I'm currently replacing the placeholder text with real content and projects.
